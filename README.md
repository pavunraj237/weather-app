# Weather App

A lightweight city weather dashboard that displays current conditions from the OpenWeatherMap API.

## Features

- Search by city
- Current temperature, humidity, and wind speed
- Weather condition icons
- A clear message when a city cannot be found

## Built with

HTML, CSS, JavaScript, and OpenWeatherMap.

## Run locally

1. Get an API key from OpenWeatherMap.
2. In dev.html, replace YOUR_OPENWEATHER_API_KEY in the apiKey constant with your key.
3. Serve this folder with a local static web server, then open /dev.html. For example, run: python -m http.server 8000

The API key is used by browser code, so it can be visible to visitors. Use a key restricted in your OpenWeatherMap account, and do not commit your personal key.
